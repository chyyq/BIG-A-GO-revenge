# A股低位假跌破放量反转监测

这是一个可直接发布到 GitHub Pages 的静态量化监测网站。每日 GitHub Actions 在 A 股收盘后运行脚本，按 V3 低位放量反转概率评分策略扫描候选股票，并更新 `data/recommendations.json`。

## 功能

- 每日自动更新：`.github/workflows/daily-update.yml` 在北京时间交易日 15:40 后运行。
- 概率评分筛选：超跌、新低、假跌破收回、放量大阳线、K线质量、换手率、主力净流入、板块强度。
- 推荐排序：按策略评分映射出的估算胜率排序，最多展示 5 只；低于 75 分自动空置，100 分以上为买入候选。
- 买卖计划：展示推荐买点、硬止损、结构止损、10%/20% 分批止盈和剩余仓位跟踪规则。
- 交易记忆：浏览器本地保存买入记录，只有保存买入后才持续监控卖点提醒。

## 本地预览

```bash
npm run dev
```

打开 `http://localhost:4173`。

## 手动更新数据

```bash
npm run update:data
```

脚本会写入 `data/recommendations.json`。V3 不再要求假跌破、2倍量、30%超跌同时出现，而是将这些条件作为高权重加分项，以保证日常能形成更可用的候选池。

## GitHub Pages 发布

1. 将本项目推送到 GitHub 仓库。
2. 在仓库 Settings -> Pages 中选择从 `main` 分支根目录发布。
3. 在 Actions 页面手动运行一次 `Daily A-share Signal Update`。
4. 之后交易日会自动更新数据。

## 数据源

- 东方财富沪深 A 股实时行情公开接口
- 东方财富行业板块近 5 日涨幅字段
- 东方财富日 K 线公开接口；本地或网络异常时回退腾讯证券复权日 K 线
- 东方财富上市公司公告接口，用于过滤重大利空、减持期、业绩暴雷等淘汰条件

页面和脚本仅用于策略监测与交易记录，不构成投资建议。
